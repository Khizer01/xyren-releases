# Xyren downloads

This repository only hosts Xyren's installers and the update feed. There is no source code here.

- **Download Xyren:** https://getxyren.pages.dev/download (or the newest release on the right)
- **What Xyren is:** https://getxyren.pages.dev
- **Help and support:** https://getxyren.pages.dev/help
- **Privacy:** https://getxyren.pages.dev/privacy

Each release has the Windows installer (`Xyren-Setup.exe`, plus a copy named by version), its
update signature (`.sig`) and `latest.json`, which installed copies of Xyren read to find
updates. Releases are signed: Xyren refuses any update whose signature doesn't match.

Please don't open issues here; use the help page instead.
